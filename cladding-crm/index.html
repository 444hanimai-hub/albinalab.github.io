Дашборд руководителя

Сумма контрактов, расходы, прибыль, маржа, динамика — в реальном времени. Все актуальные данные по проектам без звонков и сверки с менеджером.

Полная карточка проекта

Участники и контактные данные, статус задач, отгрузки с прогрессом контракта, расходы по проекту, автоматическое формирование доверенностей. Передать проект без просадки — минуты, не дни.

Автоматизации

План задач генерируется автоматически, синхронизируется с Google Календарём. Доверенности формируются из системы. Отгрузки создаются автоматически на основании доверенности, доступна выгрузка в Excel.

Гибкие права доступа

Каждый видит только то, что ему положено. Финансовый модуль защищён отдельным кодом.

Финансы и прибыль

Расходы по категориям, прибыль считается автоматически. Реальная маржа и бонус менеджеру — без часов ручной работы.

Справочники

Компании, контакты, материалы, водители, перевозчики — вводятся один раз и используются всегда. При необходимости можно быстро найти любые контакты в справочнике.
